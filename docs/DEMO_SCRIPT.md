# 演示脚本

面向 5–8 分钟的现场演示。所有步骤使用**示例数据**，不涉及真实账单。

## 准备

```bash
cd moneyflow
npm install
npm run dev
```

打开 `http://127.0.0.1:5173/`，在引导页点击「先查看 6 个月合成示例数据」。确认顶部出现「示例」标记。

演示前可先到「设置」确认：安全储备、月可变预算、月储蓄上限、目标分配日均为可读数值。

## 1. 总览（约 1 分钟）

- 指出总余额、本月收支、目标预留与自由可支配的关系：自由可支配 = 余额 − 预留 − 安全储备。
- 展示未来 30 天曲线：红点为预测期最低余额，橙色虚线为安全储备。
- 说明示例数据是 180 天合成历史，由固定种子生成，与个人账本完全分离。

## 2. 记一笔与快速记账（约 1 分钟）

- 在「流水」点击「记一笔」，输入金额后先不选分类，点击确认，展示「请选择分类」校验。
- 选择分类并保存，指出金额以整数分保存，展示格式化结果。
- 在一句话快速记账输入：`昨天买咖啡18.5元`，展示解析出的类型、金额、日期、商户、分类提示与置信度；确认后写入。

## 3. 固定计划（约 1 分钟）

- 进入「计划」，指出今日待办/逾期待确认。
- 对一条待处理期次点击「核销」，填写实际金额并确认，展示生成的流水。
- 强调：计划只是规则，核销才产生真实流水；编辑计划不会改写已核销历史。

## 4. 预测（约 1.5 分钟）

- 进入「预测」，切换 30/60/90 天。
- 悬停某一天，展示收入、固定支出、可变估计及来源（中位数/预算日均/覆盖日日均）。
- 打开「预测假设与限制」，说明未建模项与「未估计」的含义。
- 若出现「同日收支覆盖风险」，解释同日支出优先于收入的保守处理。

## 5. 目标与分配（约 1 分钟）

- 进入「目标」，新建一个目标（例如「旅行基金」，目标金额与截止日期）。
- 点击「预留」，展示自由可支配减少、账户余额不变。
- 查看「本月分配预览」，切换三种策略，说明分配是建议值、不会自动执行。
- 打开「24 个月完成推演」，指出预计完成日期与期末预留。

## 6. 决策沙盘（约 1.5 分钟）

- 进入「决策沙盘」，输入一个价格（建议高于当前自由余额，便于观察差异）、计划购买日，选择每月预留。
- 勾选「允许延期购买」，运行模拟。
- 对比「不买 / 立即 / 延期 / 分阶段」四张卡的最低余额与结论，指出哪条路径击穿安全线。
- 保存方案，展示「已保存方案」。
- 提醒：若自由余额一次足够，分阶段可能当天完成，这是不牺牲安全储备的结果，不是 bug。

## 7. 洞察、校准与备份（约 1 分钟）

- 进入「洞察」，展示周期支出候选与异常消费卡片中的证据（中位数、MAD、样本数、稳健 Z）。
- 进入「数据中心」，展示快照与校准记录；点击「滚动回测」查看 MAE/RMSE。
- 下载 JSON 备份；再选择一个损坏文件导入，展示校验拒绝且不覆盖数据。
- 强调：数据只在本地浏览器，换设备需手动备份迁移。

## 收尾话术

「它不是又一个记账本，而是把流水、预测、目标和决策放在同一条现金路径上。所有数字可解释，所有假设都写出来，不确定的时候明确说『未估计』。」

## 演示注意事项

- 不要在现场导入任何真实账单。
- 不要承诺云同步、多币种、信用卡账单或 CSV 导入——这些尚未实现。
- 发布站点为私有，需登录 Qoder 访问；不要声称匿名可打开。
- 如需重置演示：在引导页或「数据中心」重置示例数据即可。
