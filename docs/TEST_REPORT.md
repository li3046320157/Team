## 复现方式

```bash
npm install
npm test
npx tsc --noEmit
npm run build
npx playwright install chromium-headless-shell
npx playwright test
```

首次运行 E2E 前请确保没有其他进程占用 5174 端口；配置中 `reuseExistingServer: true` 会复用已启动的开发服务器。
