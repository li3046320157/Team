# 使用指南

## 1. 第一次打开

应用启动后，如果本机还没有账本，会进入引导页。

**建立个人账本**：填写主账户名称、期初余额、安全储备、月可变预算，可选填「已整理完整的起始日期」，点击「开始记账」。

**先看示例**：点击「先看 6 个月示例数据」。示例完全合成，与个人账本分开保存；侧栏会显示琥珀色「示例数据」徽标，总览顶部有横幅提示，随时可点「退出示例」。示例数据每天首次进入时按当天重建。

移动端右下角的「更多」可以看到计划、洞察、沙盘、数据中心和设置。

应用支持 PWA：浏览器地址栏或菜单点「安装」即可装到桌面/主屏，并可离线打开（只缓存界面静态资源，不缓存账本数据）。

## 2. 记一笔

进入「流水」：

- 点击右上角「记一笔」，选择支出/收入/转账，填写金额、日期、账户、分类（转账选择转出/转入账户），可选商户和备注。
- 实际交易不能记在未来日期。
- 转账不计入收入/支出，只改变账户间分布。
- 删除与固定计划关联的流水，会把该计划期次恢复为「待发生」。

**一句话快速记账**：在「一句话快速记账」输入，例如：

```
昨天买咖啡18.5元
今天兼职收入300元
```

应用会在本地解析金额、类型、日期、商户和分类提示，显示置信度与问题。确认无误后点击「按解析结果记账」；如果分类无法匹配或日期在未来，会提示改用表单。

**统计周期**：顶部「日/周/月/年」切换统计周期（周从周一开始），左右箭头切换上一/下一周期（不能浏览未来），「回到今天」一键返回当前周期。所选周期写入地址栏，刷新后保持；流水、总览与洞察页共享同一周期。收支统计、分类汇总与「较上期」环比都按所选周期计算；年视图按月分解、月视图按周分解。

**筛选**：按类型、分类筛选，搜索框支持商户、备注、分类名。流水列表每页 200 条，点击「加载更多」继续。

## 3. 管理固定计划

进入「计划」：

- 「新建计划」填写名称、金额、账户、分类、开始日期、重复频率（每天/每周/每月/每年）与间隔。
- 月度计划按原始日号推进，月底自动截断，下个月恢复。
- 待处理列表显示今天到期或逾期的期次，可以：
  - **核销**：填写实际金额、记账日期、账户、备注，生成真实流水；
  - **改期**：只移动本次，不改变重复规则；
  - **跳过**：不产生流水，该期不再提醒。
- 「全部计划」里可以停用/启用、编辑、删除。编辑时可选择「从下一期起生效」，把旧规则与新规则拆开；已核销的历史不会被改写。
- 逾期支出在预测中按「今日待付」保守计入；逾期收入不会默认到账。

## 4. 看待办与预测

「总览」给出总余额、所选周期结余（可在「账本速览」中切换日/周/月/年，并显示上期环比）、目标预留、未来 30 天余额曲线、今日待办、接下来计划、目标进度与账户分布。

「预测」页：

- 切换 30/60/90 天。
- 曲线上的红点是预测期最低余额；橙色虚线是安全储备。
- 悬停可看每天的收入、固定支出、可变估计及来源。
- 右侧显示今日待付/待收、可变消费模型（每个星期几的中位数、样本数、校准偏置）以及覆盖率。
- 如果同日固定支出会导致余额短暂跌破安全线，会出现「同日收支覆盖风险」提示。
- 「预测假设与限制」会随数据变化，说明未建模项。

**保存快照**：手动保存当前预测，用于以后校准与回看。应用也会按天自动保存（在数据中心可见）。

## 5. 查看洞察并确认

进入「洞察」：

- **周期支出候选**：例如每月同一天、同商户、金额稳定的会员。卡片显示匹配度与证据；点击「确认为计划」会创建固定计划，点击「忽略」不再提示。
- **异常消费**：每张卡显示同类历史中位数、MAD、IQR、样本数、稳健 Z 与阈值。可以确认异常或忽略。
- **小额高频**：统计低于阈值的支出，帮助发现零散消费。
- **周期选择**：顶部「日/周/月/年」决定三张卡的展示口径，并显示「本期」收支概览条；异常检测仍用最近 90 天历史池，展示按所选周期（可切换「查看全部」）；小额聚合窗口等于所选周期（当前周期只算到今天）；候选来自全部历史、不受周期影响，并标注本周期已发生次数。

阈值、窗口与样本要求可在「设置」调整；调整后洞察会按新参数重新计算。

## 6. 查看报表

进入「报表」（只读页面，不写数据、不重算预测）：

- 顶部「日/周/月/年」切换周期，右侧「导出 CSV」下载当前窗口的期数明细（UTF-8 BOM，Excel 可直接打开）。
- **KPI**：收入、支出、结余、储蓄率，均带「较上期」环比；储蓄率 = 结余 ÷ 收入，收入为 0 时不计算。
- **预算执行**：只统计可变消费（不含固定计划核销、目标购买、一次性支出与转账）；「本期折算」= 月预算按天数折算，跨月周或单日会小于月预算；当前周期会显示按当前速度预计的月底支出与超出/剩余金额，历史周期仅回看。
- **分类趋势**：窗口内支出按分类堆叠柱状图，Top6 之外并入「其他」，未分类单独成列。
- **明细表**：近 12 期（年视图 5 期）倒序排列，含执行率与支出环比；点击期数跳到该周期流水。
- 预算与趋势都遵循「历史覆盖区间」口径：未覆盖的日期不参与统计（与洞察页一致）。

## 7. 设置储蓄目标

进入「目标」：

- 「新建目标」填写名称、目标金额、截止日期、重要性（1–5）。
- 每个目标可以：
  - **预留**：从可自由支配金额中 earmark 一笔钱。账户余额不变，但可支配金额下降。
  - **释放**：撤销预留。
  - **支出**：从预留中消费，会写入真实支出流水并等额消耗预留。
  - 编辑、归档/恢复。
- 「当前最多可再预留」= 余额 − 总预留 − 安全储备。
- 「本月分配预览」支持均衡、期限优先、重要性优先三种策略；分配是建议值，不会自动执行。
- 「24 个月完成推演」沿同一条预测现金路径滚动预留，显示预计完成日期、所需月数与期末预留。
- 「目标资金流水」记录预留/释放/消费事件。

## 8. 做消费决策沙盘

进入「决策沙盘」：

1. 填写购买名称、价格、计划购买日；
2. 选择预留节奏（每月/每周）与间隔；
3. 可关联目标，已有预留会作为起始预留；
4. 勾选「允许延期购买」后，会搜索 90 天内最早安全购买日；
5. 点击「运行模拟」。

结果并列展示：

- **基准**：不购买；
- **立即购买**：今天扣款；
- **延期购买**：计划日扣款；
- **分阶段预留后购买**：按节奏预留，筹足后购买。

每张卡显示预测期最低余额、购买日、购买时已预留金额、最低点日期和结论。下方四条路径折线对比，可以直观看到哪条路径会击穿安全线。

「保存」把方案存入「已保存方案」，以后可以「套用」或删除。模拟不会写入真实账本，也不会自动扣款。

> 注意：如果自由余额一次足够，分阶段方案可能在当天完成，与立即购买接近；这不是错误，而是「不牺牲安全储备」的模拟结果。

## 9. 数据中心

进入「数据中心」：

- **备份 JSON**：下载完整备份（账户、流水、计划、目标、方案、快照、校准）。请妥善保存，备份是唯一迁移手段。
- **恢复**：选择备份文件，应用会先校验结构、金额与引用完整性，显示预览（模式、实体数量、日期范围、警告/错误）。校验通过后才出现「覆盖当前数据集」。损坏文件不会写入任何内容。
- **导出 CSV**：UTF-8 BOM，Excel 可直接打开；以 `= + - @` 开头的文本会加前缀，防止公式注入。
- **账单导入**：选择支付宝/微信/银行导出的 CSV（GBK 或 UTF-8 均可，本应用导出的 CSV 也能原样导回），按三步完成：
  1. 选择文件（不超过 10MB、5000 行）并选目标账户、重复策略与默认分类；
  2. 「生成预览」查看汇总（新增/重复/跳过笔数、收入、支出、时间范围）与前 50 行明细，可逐行修改分类；
  3. 「导入 N 笔」一次性写入账本；预览不通过的行不会写入。
  - 自动跳过的行：不计收支（转账/理财）、转账、金额或日期无法识别、未来日期、早于账户期初日、交易关闭/失败/已退款、收入退款/冲正——均需手工核对；
  - 去重：与已有流水「同日期 + 收支 + 金额 + 商户（忽略空格与大小写）」相同的行默认跳过，可切换「仍然导入」（预览中标黄提醒）；
  - 分类：按交易分类/商户关键词自动映射（外卖→餐饮、地铁→交通、工资→工资等），未命中时归入默认分类。
- **快照与校准**：
  - 「保存手动快照」记录当前预测；
  - 「运行校准」用历史快照与实际流水学习星期偏差；
  - 「滚动回测」计算 MAE/RMSE；
  - 校准记录表显示每日实际、原始预测、残差、偏置变化与有效性；
  - 「重置校准」会清空偏置并标记历史记录失效。
- **数据模式**：个人/示例切换；「重置当前」会二次确认后删除并重建当前模式数据。

## 10. 设置

进入「设置」可以修改：

- 安全储备（参与风险判断，不参与余额计算）；
- 每月可变消费预算（0 表示不设置）；
- 每月储蓄上限（0 表示不限制目标分配）；
- 目标分配日（1–31，月底截断）；
- 自然语言速记开关；
- 小额消费阈值（统计窗口由洞察页的周期选择决定）；
- 异常检测窗口、最少样本、稳健 Z 阈值；
- 周期识别容差与金额波动上限；
- 历史覆盖区间（必须早于今天，不能重叠）；
- 账户列表与新增账户；
- 到期提醒：开关立即生效，可设当天 / 提前 1 天 / 提前 3 天；开启系统通知后，打开应用时对逾期、今日到期、即将到期的固定支出发一次系统通知（同一天同一事项只提醒一次）；「导出日历（.ics）」可把未来 90 天待处理支出导入手机日历，由手机系统按时提醒。

点击「保存设置」后，顶部显示保存时间；新的预测与洞察使用新参数。

## 11. 数据与隐私

- 所有数据保存在当前浏览器的 IndexedDB 中，不上传服务器。
- 无痕模式、清理站点数据、更换浏览器或设备都会导致数据不可见；请定期导出 JSON 备份。
- 示例数据不包含任何真实个人账单。
- 不要把真实账单、密钥或含个人隐私的备份提交到公开仓库。

## 12. 常见问题

**为什么预测里某天显示「未估计」？**
该星期几最近 6 周样本不足 3 个，且没有设置月预算，也无法用覆盖日日均；模型不会把缺失当成零消费。

**为什么计划没有出现在流水里？**
计划只是规则，需要「核销」才会生成真实流水；未核销期次不影响余额。

**为什么目标预留后账户余额没变？**
预留是 earmark（资金标记），钱仍在账户里；只有「支出」才会真正记账。

**为什么沙盘分阶段和立即结果一样？**
自由余额足够覆盖全价时，分阶段可以在第一个节奏点完成；可降低价格或增加其他目标预留来观察差异。

**为什么导入备份失败？**
应用会显示具体错误（结构、金额、引用或日期）。请使用本应用导出的完整 JSON 备份，不要手工修改或使用 CSV。

**换电脑怎么办？**
在旧设备导出 JSON 备份，在新设备打开应用后到「数据中心」导入。应用没有云同步。

**为什么关掉浏览器就收不到提醒？**
应用没有后端，无法做后台定时推送；系统通知只在打开应用时检查并发送。需要按时提醒时，请在设置里「导出日历（.ics）」导入手机日历，由系统日历提醒。
