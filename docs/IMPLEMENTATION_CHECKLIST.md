# 实现清单

状态说明：`完成` = 已实现并有测试或浏览器验证；`完成（人工验证）` = 已实现并在浏览器中走通；`已知限制` = 有意未做或简化，详见 `KNOWN_LIMITATIONS.md`。

## A. 工程基础

- [x] Vite + React + TypeScript strict 工程，`npm run build` 通过。
- [x] Tailwind CSS 4 设计令牌与统一组件（按钮、卡片、表单、弹窗、徽章、空状态、Toast）。
- [x] 响应式布局：桌面侧栏、移动底部导航 + 更多抽屉。
- [x] HashRouter 九个页面与未知路径回退。
- [x] 中文界面、金额整数分格式化、日期本地化。
- [x] 统一错误与成功提示（Toast），写入失败不静默。
- [x] 设计令牌 `--site-*` 接入 Qoder Sites 工作台（appearance/radius/spacing/typography/motion）。

## B. 数据与持久化

- [x] 个人 / 示例双 Dexie 数据库，独立存储。
- [x] 账户、分类、流水、计划、计划期次、目标、目标资金事件、方案、快照、校准记录完整模型。
- [x] 初始加载：无账本 → 引导页；有账本 → 恢复上次模式。
- [x] 事务式批量写、写锁串行化、跨标签页刷新。
- [x] 示例数据固定种子、锚定今天、跨天自动重建。
- [x] 示例数据入口：引导页「先看 6 个月示例数据」+ 数据中心「数据模式」卡；示例库按本地用户隔离（`moneyflow-demo-${userId}`），每日重建，重置示例不影响个人账本。
- [x] JSON 备份包含全部实体；导入前校验结构、金额、引用完整性、日期与模式。
- [x] CSV 导出（UTF-8 BOM、公式注入防护）。
- [x] 按模式重置数据，破坏性操作二次确认。
- [x] 备份导入失败不写入任何内容。

## C. 记账与流水

- [x] 支出 / 收入 / 转账三类流水，转账不计入收支且双向更新账户。
- [x] 金额、日期、账户、分类校验；禁止未来交易。
- [x] 编辑、删除；删除计划关联流水后恢复该期待发生状态。
- [x] 按月分组、类型/分类筛选、商户/备注/分类名搜索。
- [x] 一句话快速记账：本地规则解析金额、类型、日期、商户、分类提示；歧义/未来日期不自动落库；确认后才写入。
- [x] 流水与账户余额、预测、校准失效联动。

## D. 固定计划

- [x] 计划 CRUD、启用/停用、删除保护。
- [x] 日/周/月/年重复规则与间隔；月/年按原始日号推进，月底截断、后续恢复。
- [x] 计划期次视图：待处理、未来 60 天、最近处理记录。
- [x] 核销：实际金额/日期/账户/备注 → 生成真实流水与计划期次记录。
- [x] 跳过本期；仅本次改期；编辑时「从下一期起」拆分规则。
- [x] 逾期支出按今日待付保守计入预测；逾期收入不默认到账。
- [x] 同日收支按「支出先于收入到账」做覆盖风险提示。

## E. 预测

- [x] 统一预测引擎同时服务总览、预测页、目标推演、沙盘。
- [x] 可变消费四级来源：同星期中位数 → 月预算日均 → 覆盖日日均 → 未估计。
- [x] 最近 6 周、每周星期几至少 3 个样本才使用中位数。
- [x] 覆盖率、训练日、样本数、来源、假设全部可见。
- [x] 安全储备风险：最低余额、首次低于安全线、低于天数、首次为负。
- [x] 30/60/90 天切换；余额曲线、最低点标注、安全线、每日明细。
- [x] 今日待付/待收、同日覆盖缺口提示。
- [x] 预测快照不可变保存；每日自动 + 手动快照。

## F. 洞察

- [x] 周期支出候选：同商户、金额稳定（CV 阈值）、间隔接近周/月/年、样本充足；匹配度与证据展示。
- [x] 确认候选后创建计划；忽略候选。
- [x] 异常消费：MAD 稳健 Z 为主，MAD=0 回退 IQR / 倍数规则；只用当天之前历史；证据含中位数、MAD、IQR、样本数、阈值。
- [x] 异常确认/忽略，确认记录保存。
- [x] 小额高频统计与阈值/窗口可配置。
- [x] 检测参数在设置中可调，变更后重新计算。

## G. 目标与沙盘

- [x] 目标 CRUD、归档/恢复、逾期显示、优先级 1–5。
- [x] 预留 / 释放 / 消费；预留只 earmark 可自由支配金额；消费写入真实支出并消耗预留。
- [x] 最大可预留 = 余额 − 总预留 − 安全储备。
- [x] 均衡 / 期限优先 / 重要性优先三种权重策略。
- [x] 带上限的加权水位分配，避免单目标吞掉全部预算。
- [x] 24 个月滚动完成推演，策略切换实时更新。
- [x] 目标资金流水（预留/释放/消费）展示。
- [x] 沙盘四路径：基准、立即、延期、分阶段预留后购买。
- [x] 最早安全购买日（后缀最小值搜索 90 天窗口）。
- [x] 分阶段预留计划：按周/月节奏，考虑已有预留、安全储备与自由余额。
- [x] 沙盘方案保存、套用、删除；模拟不写入真实账本。
- [x] 四路径折线对比图与文字结论、限制说明。

## I. 到期提醒与 PWA

- [x] PWA：manifest、SVG 图标 + 脚本渲染 192/512 PNG、Service Worker（导航 network-first + 静态 SWR），仅生产构建注册；离线可打开。
- [x] 到期提醒纯函数：按 90 天回溯窗口分桶（逾期 / 今日到期 / 即将到期），默认只提醒支出。
- [x] 提醒偏好：localStorage 持久化、开关立即生效、提前 0/1/3 天可选、损坏数据回退默认值。
- [x] 系统通知：打开应用后检查（1.2 秒延迟 + 每 60 秒）、按需请求权限、同一天同一事项只提醒一次（`tag: moneyflow-due` 覆盖）、权限拒绝或浏览器不支持时静默降级、演示模式不弹通知。
- [x] 导航徽标：桌面计划项角标、移动「更多」红点；总览「今日待办」附逾期批量处理入口。
- [x] 日历导出：RFC 5545 .ics（75 字节折行、`\ ; ,` 转义、全天事件 + 09:00 VALARM）。
